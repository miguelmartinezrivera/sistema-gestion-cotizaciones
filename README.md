# Sistema de Gestión de Cotizaciones

Sistema desarrollado como proyecto de portafolio para gestionar productos, proveedores, precios y cotizaciones comerciales mediante una API REST.

## 🎯 Objetivo

Desarrollar una solución backend que permita centralizar la información necesaria para elaborar cotizaciones, facilitando la gestión de productos, proveedores y precios.

## 🚀 Funcionalidades

- Gestión de productos.
- Gestión de proveedores.
- Registro de precios por proveedor.
- Creación y consulta de cotizaciones.
- Gestión del detalle de productos de una cotización.
- Consulta de información mediante API REST.

## 🛠️ Tecnologías

- Python
- FastAPI
- MySQL
- SQL
- API REST
- Git
- GitHub

## 📁 Estructura del proyecto

El proyecto será organizado separando las responsabilidades de modelos, esquemas, rutas, servicios y acceso a datos.
